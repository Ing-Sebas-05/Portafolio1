# Mi Portafolio Personal en Proceso

##  Sobre mí

¡Hola! Soy **Sebastián Chavarría Posada**, estudiante de Ingeniería de Software, apasionado por la tecnología, la programación y el desarrollo de soluciones digitales.

Este proyecto consiste en un portafolio web personal creado para presentar mi perfil profesional, mostrar mis proyectos y dar a conocer mis conocimientos en desarrollo de software.

## Tecnologías utilizadas

- **HTML5:** Estructura y contenido de la página web.
- **CSS3:** Diseño, estilos y presentación visual.
- **JavaScript:** Funcionalidad e interactividad del sitio web.

## Estructura del proyecto

```text
Portafolio1/
│
├── data/
│   └── proyectos.js
│
├── img/
│   ├── .gitkeep
│   └── perfil.jpg
│
├── estilos.css
├── index.html
├── README.md
└── script.js
```

### Descripción de los archivos

| Archivo / Carpeta | Descripción |
|---|---|
| `data/` | Carpeta destinada a los datos del proyecto. |
| `proyectos.js` | Archivo donde se organizan los datos de los proyectos. |
| `img/` | Carpeta que almacena los recursos gráficos. |
| `perfil.jpg` | Imagen de perfil personal. |
| `estilos.css` | Contiene los estilos visuales de la página. |
| `index.html` | Archivo principal que contiene la estructura del portafolio. |
| `script.js` | Contiene la lógica y funcionalidades JavaScript. |
| `README.md` | Documentación del proyecto. |

## Características del portafolio

- Presentación personal.
- Información sobre mi perfil académico.
- Visualización de proyectos de desarrollo.
- Diseño web adaptable a diferentes dispositivos.
- Organización del código en diferentes archivos y carpetas.

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Ingresar a la carpeta del proyecto:

```bash
cd Portafolio1
```

3. Abrir el archivo `index.html` en el navegador.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para ejecutar el proyecto localmente.
